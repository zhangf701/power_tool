# 参数校核与标幺值：线路（详细手册）

## 1. 用途
本页用于线路参数核对、单位换算与标幺化，帮助发现输入不一致或越界值。“线路参数计算”弹窗包含“架空线参数计算”和“电缆参数计算”两个页签，可由几何、土壤、绝缘和护层数据反算序参数。

## 2. 建议流程
1. 输入额定电压、容量基准、线路长度。
2. 输入或回填正序参数（R1/X1/C1）和零序参数（R0/X0/C0）。
3. 如需由几何反算，点击“线路参数计算”，选择架空线或电缆。
4. 电缆页填写导体、绝缘、敷设几何、金属护层和护层接地方式后，查看结果中的“零序回流方式”和 X0/X1 说明。

## 3. 电缆零序回流自动推断
电缆页默认按护层接地方式自动推断零序回流模型，普通用户无需手动选择：

- 未启用金属护层或单端接地：按大地回流。
- 两端接地：按护层+大地并联回流，使用三芯线+三护层的多导体矩阵并对护层作 Kron 消元。
- 交叉互联：同样按护层+大地并联回流近似，同时在说明中提示交叉互联可降低工频护层环流损耗。

该处理参考 PSCAD Line Constants Program 的思路：不是预设 X0 必然大于或小于 X1，而是让芯线、护层和大地回路共同决定阻抗矩阵，再做导体层消元。界面保留“高级：手动指定零序模型”，可强制选择“大地回流”“护层回流（同轴下限）”或“护层+大地并联（PSCAD/Kron近似）”，用于厂家参数复核或特殊回流路径。

## 4. 如何理解 X0 小于 X1
X0 小于 X1 不是所有电缆的通用规律。它通常只在金属护层/屏蔽层形成近距离零序回流通道时出现：护层中的回流分量会抵消芯线零序电流产生的部分外部磁场，使等效电抗下降；同时护层电阻和环流损耗会抬高等效 R0。

当护层单端接地、未可靠形成连续回流，或主要通过大地/接地网/ECC 回流时，零序回路面积变大，X0 可能显著大于 X1。三芯统包、铠装、钢管、电缆隧道内邻近金属回流等结构应按单独模型或厂家数据处理，不应直接套用单芯护层模型。

## 5. 核查重点
- R/X 比是否落在常见范围。
- C1 数值与线路电压等级、绝缘半径和介电常数是否匹配。
- 护层电阻、护层半径、护层接地方式对 R0/X0 很敏感，应核对来源。
- 结果说明中会写明零序回流方式是“自动推断”还是“高级设置手动指定”。
- 投运、保护整定或短路容量校核前，应优先采用厂家序阻抗表、实测值或正式线常数工具结果。

## 6. 常见错误
- 把每公里参数当总参数输入。
- μF 与 F 单位混淆。
- 将架空线“X0 通常远大于 X1”的经验直接套到两端接地单芯电缆。
- 将“护层回流（同轴下限）”结果直接作为保护整定参数。

## 7. 工程建议
结果可作为短路与潮流初始参数来源，但投运前建议与实测、设计书、厂家电缆序阻抗表或 PSCAD/EMTP/OpenDSS 等正式线常数结果再次核对。对于交叉互联长段、三芯统包电缆、铠装/钢管电缆、带 ECC 或复杂接地网的工程，应保留参数来源和回流假设说明。
